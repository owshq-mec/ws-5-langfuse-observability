Definition

A context layer turns company systems into facts an agent can trust.

ConnectedEvery system, one place.
StructuredA shared vocabulary: customer, contract, policy.
TemporalKnows when each fact was true.
TraceableEvery fact points to its source.
ServedOne interface for every agent.
Vocabulary

One idea, five names.

Context layerThe thing you build. The most common name.the product
AI context platformHow analysts name the market category.the category
Context graphThe data inside: entities and dated facts with sources.the data structure
Context engineeringThe practice of giving an agent the right context.the discipline
MCPModel Context Protocol. How agents call the layer.the protocol

At Orbisa the context layer is called Helix.

Why now

Every agent needs the same context.
Build it once.

01One answerSlack, the wiki and the contract stop competing. The layer reconciles them.
02The right date"Who approved refunds in December?" has a different answer than today.
03ProofAn answer with a source can be checked. An answer without one cannot.
04ReuseSupport bot, sales assistant, coding agent: same layer, same MCP server.

GRAPH · follow the edges

Nodes have labels and properties. Relationships have a type, a direction and properties, such as valid_at.

Ask the graph in Cypher.

Patterns look like the drawing: (a)-[r]->(b). Graphiti stores every fact as a RELATES_TO edge with its dates.
