Why not paste everything?

More context is not better context.

Chroma tested 18 models: as the input grows, answers get less reliable, even on simple tasks. They call it context rot.

ANTHROPIC'S MODEL An LLM has an attention budget. Every token spends some of it. Treat context as a finite resource.
So Helix returns facts, not files.Ten dated facts with sources beat a 40-page policy dump.

ConnectedEvery system, one place.

How retrieval grew up

Chunks → graphs → graphs with time.

2020 →Vector RAGSplit documents into chunks. Return the top-k most similar.
fast lookupsno relations, no time
2024 →GraphRAGExtract entities and relations, group them into communities, summarize each.
whole-corpus questionsno notion of time
2025 →Temporal knowledge graphFacts are edges with validity dates and sources. Old facts are closed, not deleted.
"what was true when?"← Helix (Graphiti)

Building a context layer

Six habits, four mistakes.

DO
Keep provenance. Every fact links to its source.trust
Model time. Close old facts with a date.temporal
Resolve entities. One person, many names.ontology
Return little. Few, high-signal facts.context rot
Respect permissions. Filter by who asks.security
Measure retrieval. Separately from the answer.today
DON'T
Paste whole documents into the prompt.
Overwrite or delete old facts.
Let each team invent its own vocabulary.
Trust a fluent answer with no source.
Start smallPick a few high-value questions first. Grow the layer from there.
