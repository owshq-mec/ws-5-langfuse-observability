Why not paste everything?

More context is not better context.

Chroma tested 18 models. They kept the task the same and only made the input longer. Answers still got less reliable, even on simple tasks. They call it context rot.

ANTHROPIC'S MODEL An LLM has an attention budget, like a person's working memory. Every token you add spends some of it, so the tokens that matter get less focus. Treat context as a finite resource: send the smallest set of high-signal tokens that gets the job done.
So Helix returns facts, not files.Ten dated facts with sources beat a 40-page policy dump.
Chroma, "Context Rot", 14 Jul 2025 · Anthropic, Sep 2025shape illustrative, not report data
1The input growsEach line is a model. Same task, longer input, lower reliability.
2Why it fallsEvery token looks at every other token. n tokens make n² pairs.1K tokens→ 1M pairs10K tokens→ 100M pairs
3A slope, not a cliffModels stay capable, but lose precision. Most training texts are short, so long inputs get less practice.

New nameWhat is Graphiti?

An open-source framework (by Zep, Apache-2.0) that builds temporal context graphs for AI agents. Helix uses it to extract, store and search facts.

  • Input: episodes, each a piece of text with a date.
  • Extract: an LLM finds entities and facts and merges duplicates.
  • Time: each fact gets a valid-from / valid-until. A contradiction closes the old fact, it is not deleted.
  • Incremental: new episodes update the graph, no full rebuild.
  • Search: meaning + keywords + graph links.
github.com/getzep/graphiti · stored in Neo4j

What is Neo4j

A database built for graphs. It stores a property graph:

nodea thing, with labels and properties(:Entity:Person {name: "Tomás Herrera"})
relationshipa link, with a type, a direction and properties-[:RELATES_TO {fact, valid_at, invalid_at}]->

Each node points straight to its relationships. Following an edge is a pointer hop, not a JOIN.

What is Cypher

Neo4j's query language. You draw the pattern you want, in text:

(a:Entity)-[r:RELATES_TO]->(b:Entity)

Why it matters for Helix
Learn Cypher, learn most of GQL. The patterns and the MATCH / WHERE / RETURN shape carry over.
No lock-in to one database. Graphiti already ships drivers for Neo4j, FalkorDB, Kuzu and Amazon Neptune.
Tables can join in. With SQL/PGQ, a SQL database can run the same graph patterns.
Same move as MCP. Once a language is a shared standard, tools, drivers and skills grow around it. That is why it is safe to build on.
