Orbisa Wiki : INC-2291 Postmortem — Tracking API outage

Created by Ingrid Holm, last modified by Daniel Okafor on Aug 21, 2026
IncidentINC-2291
SeveritySEV-1
DateAugust 19, 2026, 14:05–17:17 UTC
Duration3 hours 12 minutes
ImpactOrbisa Track API returned HTTP 503 for all customers. Enterprise customers affected include Orion Freight Systems and Kodiak Cold Chain.

Root cause

Release v4.12 of the tracking-ingest service changed the Kafka consumer batch size. Consumers fell behind, the API read stale partitions, and health checks failed.

Fix

Rolled back to v4.11. Added a consumer-lag alert at 30 seconds.

Follow-ups

  • Canary deploys for tracking-ingest (owner: Daniel Okafor).
  • Customer Success to contact affected Enterprise customers about service credits (owner: Aisha Bello).
